# Paradex Bollinger Bands Calculator

A Python application that fetches 1-month of 1-minute candlestick data from Paradex API and calculates Bollinger Bands technical indicator.

## 📋 Task Description

**Objective:** Call the Paradex API to obtain one month's worth of 1-minute candlestick (K-line) data for any trading pair, and calculate its Bollinger Band indicator.

## ✨ Features

- 🔐 Secure wallet generation for Paradex API authentication
- 📊 Fetches real-time candlestick data from Paradex (testnet/mainnet)
- 📈 Calculates Bollinger Bands indicator (SMA, Upper/Lower Bands, %B, Bandwidth)
- 📉 Beautiful visualization with matplotlib
- 💾 Exports data to CSV
- 🎯 Market signal interpretation (overbought/oversold/trend analysis)
- 📁 Organized data storage in `data/` subfolder

## 📈 Bollinger Bands Explanation

### What are Bollinger Bands?

Bollinger Bands is a technical analysis tool created by John Bollinger consisting of:

- **Middle Band (SMA):** Simple Moving Average over N periods (default: 20)
- **Upper Band:** SMA + (2 × Standard Deviation)
- **Lower Band:** SMA - (2 × Standard Deviation)

### Key Indicators

- **%B (Percent B):** Shows price position within the bands
  - `%B > 100`: Price above upper band (potentially overbought)
  - `%B < 0`: Price below lower band (potentially oversold)
  - `%B = 50`: Price at middle band

- **Bandwidth:** Measures volatility
  - Wide bands = High volatility
  - Narrow bands = Low volatility (potential breakout coming)

### Trading Signals

| Signal | Interpretation |
|--------|---------------|
| Price touches upper band | Potential overbought, consider selling |
| Price touches lower band | Potential oversold, consider buying |
| Bands squeeze (narrow) | Low volatility, potential breakout coming |
| Bands expand (wide) | High volatility, strong trend |
| Price walks the band | Strong trend (upper = bullish, lower = bearish) |

## 🔒 Security Best Practices

⚠️ **IMPORTANT SECURITY NOTES:**

1. **Never share your private key** with anyone
2. **Use TESTNET for learning** - Set `USE_TESTNET = True` (though mainnet is safe for reading public data)
3. **Don't commit private keys to GitHub** - The `.gitignore` file already excludes sensitive data
4. **For production:**
   - Use environment variables
   - Create separate config files
   - Never hardcode keys in scripts

### Using Environment Variables (Recommended)

```bash
# Set environment variable
export PARADEX_PRIVATE_KEY="0xYOUR_KEY_HERE"
```

```python
# In config.py
import os
PRIVATE_KEY = os.environ.get('PARADEX_PRIVATE_KEY', '')
```

### What's Protected by .gitignore

The `.gitignore` file automatically excludes:
- Python cache files (`__pycache__/`, `*.pyc`)
- Virtual environments (`venv/`, `env/`)
- Output data folder (`data/`)
- IDE settings (`.vscode/`, `.idea/`)
- OS files (`.DS_Store`)

## 🧪 Testnet vs Mainnet

### Testnet
- ✅ No real money at risk
- ✅ Same API functionality
- ✅ Perfect for testing
- ⚠️ May have limited data availability

### Mainnet (Default - Safe for Public Data)
- ✅ Complete historical data
- ✅ Real market conditions
- ✅ **Safe for reading public candlestick data** (no trading)
- ✅ 30+ days of 1-minute resolution available

**Note:** This application only **reads** public market data, so using mainnet is safe!


### Error: "paradex-py not installed"
```bash

```

### Error: "No private key found"
1. Run `python main.py` to generate wallet
2. Copy the private key displayed
3. Paste in `config.py` (line 4)
4. Run `python main.py` again

- Try different time periods (reduce `DAYS` to 7 or 14)
- Check market symbol is correct
- Verify internet connection
